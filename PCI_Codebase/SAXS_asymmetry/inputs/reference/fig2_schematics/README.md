# Figure 2 detector image assets

`saxs_fig2.png` and `pci_fig2.png` are unmodified image objects extracted from
the user-provided paper, physical PDF page 4 (printed page 017201-3), Figure 2.
They are the SAXS and PCI reference images, not new offset-dependent results.

Source: Huang et al., *Demonstration of full-scale spatiotemporal diagnostics of
solid-density plasmas driven by an ultra-short relativistic laser pulse using
an X-ray free-electron laser*, Matter and Radiation at Extremes 11, 017201
(2026), https://doi.org/10.1063/5.0279974.

The original PDF is `017201_1_5.0279974.pdf`. Images were extracted with pypdf
from `reader.pages[3].images[10]` and `[11]`, respectively.
